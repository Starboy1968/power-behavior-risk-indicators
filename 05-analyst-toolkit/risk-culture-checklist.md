# Risk Culture Assessment Checklist

Rate each item with an evidence grade, not a score:

- **Not seen**: no evidence either way
- **Single observation**: seen once, one source
- **Repeated pattern**: seen several times, one source type
- **Corroborated pattern**: repeated and confirmed by an independent source

Record the evidence reference for every item (meeting date, document, interview ID). Items are phrased so that "yes" is a **concern**.

## Tone and language
| # | Check | Grade | Evidence ref |
|---|---|---|---|
| 1 | Controls or reviews described as "just a formality," "box-ticking," or obstacles | | |
| 2 | "Leadership already decided" or similar used before a risk review is complete | | |
| 3 | "We've always done it this way" or "never had a problem" offered as main justification | | |
| 4 | Decisions recorded in passive voice with no named owner | | |

## Meetings and forums
| # | Check | Grade | Evidence ref |
|---|---|---|---|
| 5 | Most senior attendee gives a view first, and outcomes usually match it | | |
| 6 | The same roles are interrupted, redirected, or talked over across meetings | | |
| 7 | Items are announced rather than discussed; "settled already" | | |
| 8 | Approvals are fast and rarely questioned; return or rejection rarely happens | | |

## Dissent and speaking up
| # | Check | Grade | Evidence ref |
|---|---|---|---|
| 9 | Concerns raised in meetings are missing from minutes | | |
| 10 | Concerns are raised once and not followed up or tracked | | |
| 11 | People who raised issues are later sidelined (route to HR, ethics, or audit; do not investigate yourself) | | |
| 12 | Staff share concerns only off the record; formal channels are rarely used | | |

## Authority and structure
| # | Check | Grade | Evidence ref |
|---|---|---|---|
| 13 | Risk owners approve their own risk acceptances | | |
| 14 | Real approval path differs from the delegation-of-authority matrix | | |
| 15 | A project, vendor, or unit is treated as "protected" by a sponsor | | |
| 16 | Requester, evaluator, and approver are the same person or reporting line | | |
| 17 | Conflict-of-interest declarations are missing or stale for key decision-makers | | |

## Third parties
| # | Check | Grade | Evidence ref |
|---|---|---|---|
| 18 | A critical supplier relationship depends on one internal person | | |
| 19 | Due diligence completed after contract, PO, or access | | |
| 20 | Supplier information reaches risk teams only through a single intermediary | | |

## Reporting and follow-through
| # | Check | Grade | Evidence ref |
|---|---|---|---|
| 21 | Reported status is green while ground-level evidence shows problems | | |
| 22 | Risk assessments copied forward unchanged for many cycles | | |
| 23 | Exceptions renewed repeatedly with the same rationale | | |
| 24 | Finding due dates moved repeatedly without evidence of progress | | |

## Positive signals (record these too; they balance the picture)
- Minutes record dissent and how it was resolved
- Leaders ask for bad news and visibly act on it
- Exceptions close on time or are formally re-accepted at a higher level
- Second-line challenge is documented, including when it changed an outcome
- More than one person can speak to every critical supplier

## Interpreting results
Look for **clusters**, not single items. Three or more corroborated items within one area (for example, Authority and structure) usually justify a written observation and a conversation with the area's leader. Use the [escalation guide](escalation-decision-guide.md) for anything involving possible misconduct, conflicts of interest, or retaliation.
